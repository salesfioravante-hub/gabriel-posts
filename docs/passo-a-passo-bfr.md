# Passo a passo para a troca de assessoria (texto oficial, enviado pelo Gabriel em 26/11/2026)

1. Faça o login na plataforma da XP: https://portal.xpi.com.br/default.aspx
2. É necessário que seja via site/navegador. Via aplicativo, por questão de segurança, não é possível.
3. No menu superior, clique em ATENDIMENTO.
4. Clique em TROQUE DE ASSESSOR.
5. Clique em ALTERAR.
6. Selecione o motivo mais adequado e digite no campo de texto: "Assessoria especializada, relacionamento com o assessor solicitado".
7. No campo Assessor, preencha com o nosso código: 67544 - Lenon Rissardi.
8. Clique no botão amarelo "Enviar informações".

Ainda não é cliente? Abra a conta com a BFR: https://cadastro.xpi.com.br/v3/cadastro/nome?assessor=A67544
